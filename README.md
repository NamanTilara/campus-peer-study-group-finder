# StudyCircle: Campus Peer Study Group and Exam Prep Circle Finder

A web project where students find, join and start peer study groups for their subjects and exams.

## Files

| File | Purpose |
|------|---------|
| `index.html` | Page structure (header, search, circles, how it works, start a circle form) |
| `style.css` | All styling, responsive layout and dark mode |
| `script.js` | Posting circles, joining with registration number, circle chat |
| `PROJECT_NOTES.md` | Features, limitations and viva notes |

## How to run

1. Keep all four files in the same folder.
2. Double-click `index.html` to open it in Chrome, Edge or Firefox.
3. No installation or internet is needed (fonts fall back to system fonts offline).

## Features

- Browse study circles and filter them by subject area.
- Start a circle with host name, registration no. and B.Tech year.
- Join a circle with an 8-digit registration number (no duplicates, seat limit).
- Members-only chat inside each circle, with file attachments for notes.
